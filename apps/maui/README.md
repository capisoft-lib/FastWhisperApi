# Capisoft AI Transcribe App (MAUI)

Cross-platform client app for:

- Windows
- Android
- iOS
- MacCatalyst

## Open Solution

- `apps/maui/Capisoft.AI.TranscribeApp/FastWhisperMaui.sln`

## Build Examples

```powershell
dotnet build apps/maui/Capisoft.AI.TranscribeApp/FastWhisperMaui.sln -f net10.0-windows10.0.19041.0
dotnet build apps/maui/Capisoft.AI.TranscribeApp/FastWhisperMaui.sln -f net10.0-android
```
